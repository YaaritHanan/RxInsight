# RxInsight 💊

RxInsight is an interactive pharmacovigilance application for exploring adverse drug reactions and medication safety data.

## Features

* 🔎 Search for medications by brand or generic name
* ⚠️ Analyze reported adverse effects
* 📊 Visualize adverse-effect statistics
* 👥 Analyze patient demographics
* 🌐 Explore medication safety patterns
* 📈 Interactive data visualizations

## Data Source

The application uses data from the FDA Adverse Event Reporting System (FAERS) through the OpenFDA API.

## Technologies

* Python
* Streamlit
* Pandas
* Plotly
* OpenFDA API
* Poetry

## Installation

```bash
poetry install
```

## Target Audience

RxInsight is designed for the **general public and non-medical users**, providing accessible and easy-to-understand insights into medication safety and reported adverse effects.

The application is **not intended for healthcare professionals or clinical decision-making**.

## Disclaimer

RxInsight is intended for informational and educational purposes only.

The information presented by the application should not be considered medical advice, diagnosis, treatment, or a substitute for consultation with a qualified healthcare professional.
